# ITC WEB
Proyek ini merupakan salah satu program yang ada di ITC sebagai media informasi terkait organisasi ITC, kegiatan, dan berbagi ilmu seputar informasi, teknologi, dan komunikasi. 

Link : itcmipaunsoed.my.id

## Fitur
 1. Memiliki halaman admin yang mengolah data artikel dengan fitur CRUD
 2. Tampilan frontend yang menarik dan responsif serta memiliki animasi sederhana
 3. Halaman blog yang terdiri dari artikel-artikel kegiatan serta informasi seputar teknologi
 4. Memiliki halaman admin yang mengolah data artikel dengan fitur CRUD
 5. Memiliki fitur keamanan untuk menuju ruang admin
